# Steve surface changes: current-build reference migration

This checkpoint prepares SRD placement and single shader-engine scratch sizing
for this machine's 24H232 cache. It does not install or enable those changes.
The existing GL/Metal, SubmitGuard, LegacyBlend and VCN owners remain in place.
The broader migration and hardware acceptance are still incomplete.

## Rejection root cause

Steve master 31fcc872807ae06f59d99016dd5ef80d8996e8ec has a Sequoia constructor
reference at displacement field 0x35 expecting image RVA 0x38b8ef30. On 24H232,
that address 0x7ffb412e5f30 is an `__objc_superrefs` slot which points to the
`_OBJC_CLASS_$_GFX9_MtlTexture` symbol. The actual constructor uses the next
relevant slot at 0x7ffb412e5f40, bound to the correct symbol
`_OBJC_CLASS_$_GFX9_MtlRenderPipelineState`. The old resolver therefore rejects
correctly. This does not show a broken GPU or justify accepting observed targets
without identifying them.

The native init, override and device-settings functions retain their complete
reference hashes. Constructor, submit and scratch instruction streams retain
all non-relocation bytes; their relocation operands changed. Current native
function sizes, addresses and raw hashes are pinned in surface-24H232.json.
The override's 389-byte complete context is also pinned. Generation independently
checks the superclass slot's section and class-symbol identity, the 3.0 constant,
the named native settings-dump stub, all source function hashes and complete
file pages against embedded CodeDirectory hashes. These hashes establish page
integrity against the embedded table; they are not a CMS trust evaluation.

## Prepared artifacts and retained semantics

`tools/gen_surface_profile.py` produces UserSurface24H232Data.hpp from read-only
cache files. `--check` reproduces it byte for byte. It preserves upstream SRD
assembly intent and complete native call targets. The Sequoia scratch generator
retains the allocation/free tail and changes shader-engine multiplication only
for the specific APU in each payload. CU and shader-array factors, unsigned
32-bit overflow and other GPUs keep native behavior. This does not increase
available VRAM or establish a measured speed benefit.

The generated data uses the existing local descriptor and shared-cache resolver.
No second surface hook, SubmitGuard, LegacyBlend or full video adaptation module
is imported. Its full constructor reference recognizes the already-applied local
LegacyBlend branch. A runtime installer must still explicitly coordinate that
shared gate, rather than treating partial application of all SRD sites as success.

Build-time helpers and the initializer test are adapted from Steve's generator
and CPU harness at the pinned revision. The reader now requires an explicit UUID;
no default Tahoe target can accidentally authorize generation. The generated
profile remains exact-build data, not arbitrary future-ABI compatibility.

## Exact-location resolver optimization

`UserCacheResolver::resolveExact` checks the supplied 16-byte cache UUID and magic
before verifying generated fixed RVAs. Complete native/patched functions, bounds,
external direct/GOT/branch-island identities, disjoint ranges and relocation
binding remain mandatory. A UUID mismatch or moved function rejects without
scanning elsewhere. The ordinary relocation-aware resolver is unchanged and
remains the default. There is no cross-process positive-match cache.

In this host's read-only file-cache diagnostic, the current generated surface
profile passes for all six variants. Ordinary location scanning required 8,517
reads and about 31–38 ms CPU per pass; fixed locations required 4,002 reads and
about 5–6 ms. These single-process diagnostic timings include file-reader overhead,
are not rigorous benchmarks, and say nothing about GPU frame rate or live kernel
startup latency. The fixed-location API is not yet selected by a running hook.

## Evidence and remaining integration

- 1110 ASan/UBSan reference cases cover every external target/binding, complete
 function mutations, missing bytes, every device, repeated patches and the local
 LegacyBlend variant. GOT aliases with the same bound symbol are legitimate;
 negative binding tests corrupt the bound identity instead of assuming that any
 changed GOT address must fail.
- 394656 actual CPU scratch cases cover every 16-bit PCI ID, target-specific sizing,
 high-bit lookalikes, zero factors, overflow and the unchanged allocation/free tail.
- Each of six SRD initializer variants passes 18,432 randomized native init/override
 comparisons plus the full 65,536-ID sweep. Only the intended target SRD bit changes;
 native override and dump callbacks remain. A separate native counterexample must
 fail the intended changed-behavior condition.
- 71 ASan/UBSan exact-location cases cover UUID/magic, native/patched code, each
 code/displacement byte, unavailable header, moved function and fresh revalidation.

build/steve-followup-20261028/surface-audit/. Generated payload JSON is under
build/steve-surface-24H232-20261028/generation/.

The planner, private adapter within the existing map lease, ownership rules,
